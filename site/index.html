Useful details.

A straightforward Zsh experience, without unnecessary complexity. Git state, development environments and elapsed time appear in the prompt.

Git keeps up.

Branch, tag, dirty files, merges and rebases. Git status updates asynchronously, so your prompt stays fast even in a huge repository.

Fits your terminal.

Every part of the prompt responds to the window’s width. Wide window or narrow terminal, the useful context stays readable.

Knows your project.

Node.js, Python, Go and PHP versions appear automatically. Activate a Python virtual environment or Conda environment and Jovial shows it, too.

Time at a glance.

See the execution time after a command finishes.

At home in light and dark.

Jovial detects your terminal’s background and adjusts its prompt colours automatically. Use the appearance switch to see it adapt.
